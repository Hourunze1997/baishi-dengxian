# 百世登仙 · 文字轮回修仙

一款单文件网页文字修仙游戏。双击 `百世登仙.html` 即可游玩（手机/电脑浏览器均可，`img` 文件夹需与 HTML 放在一起）。

## 玩法

- **一世一轮回**：随机出身（8 种）× 灵根（5 档）× 命格（随机 1~2 条），开局纯看天命，不服可"改签"
- **推演天机**：点一下，岁月流转 1~3 年，修为自行增长；随机触发 **77 个原创事件**（奇遇/危机/人情/道心/情缘/宗门/天下）。事件弹出时必须先抉择，不许跳过
- **事件与属性深度绑定**：混沌灵根/废灵根/天灵根各有专属事件；根骨≥9 触发金刚关、悟性≥10 仰问苍穹、气运≥10 天命垂顾、道心≥10 不动明王关；将门/书香/商家/皇子各有出身事件；散修没有宗门选项、穷人没有砸钱选项——同一事件在不同人手里是 2~5 个选项
- **随境界循序渐进**：事件修为收益随境界放大（每境 +45%），早期事件后期不再鸡肋；岁月流转的闲笔文案按凡人/筑基/元婴分三档
- **历劫录**：此生每件大事（含你的选择与完整结果）自动留档，随时翻看
- **天道无常**：任何抉择结算后约四成概率追加随机变数，且变数随属性而变——气运高则好事多坏事少，根骨高摔跤只算磕皮，悟性高更易触类旁通；同一选项永不出现两次相同结果
- **境界突破**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升
- **寿元大限**：寿元耗尽即身死，死后自动生成这一生的**传记**，并按成就凝结**道韵**
- **轮回点化**：道韵可购买 14 种前世天赋，永续生效（道体天成 / 剑心通明 / 仙缘牵引……）
- **天外飞仙**：自己玩自己爽——"一生详录"（右上角 ☰）里有灵石/道韵无限领取按钮，开局"天命改签"不限次免费

### 本作在经典循环之外加的系统

| 系统 | 说明 |
|---|---|
| 宗门功法 | 五大宗门各 2 部功法，走贡献换功法、宗门差事、大比扬名路线 |
| 道侣情缘 | 邂逅 → 结缘 → 双修/遇险/生离死别的完整事件链 |
| 本命法宝 | 奇遇寻宝 + 灵石淬炼，凡品一路升到仙品 |
| 世界大势 | 魔潮、妖乱、灵气潮汐、宗门大比、仙缘盛会，每隔数十年降临 |
| 一生传记 | 死亡时按编年史自动生成半文半白的一生总结 |
| 心魔/悟道 | 道心不稳闭关会走火入魔；参悟事件可进入悟道状态 |

## 配图说明

全部配图由 AI 生成（Pollinations 免费接口），按槽位命名存放在 `img/`：

- `title` 标题图 / `death` 轮回 / `ending` 飞升 / `roll` 开局 / `daolv` 道侣 / `fabao` 法宝
- `origin_*` 八种出身立绘
- `brk_0`~`brk_9` 十境突破场景
- `sect_*` 五大宗门

图片缺失时游戏会自动降级为印章字占位，不影响游玩。想换图/加图：改 `gen.py` 里对应槽位的提示词后运行 `python3 gen.py 槽位名`（可加环境变量 `SEED_OFF=数字` 换随机种子）。

## 开发

- 代码分片与逻辑模拟脚本在 `dev/`（`sim.js` 可用 node 空跑模拟整世流程做回归测试）
- 存档在浏览器 localStorage（键 `bsdx`），"一生详录"里可清档重开
